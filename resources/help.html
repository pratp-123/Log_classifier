Input Format Guide

Learn how to prepare your CSV file for log classification.

Required CSV Format

Your CSV file must be a standard comma-separated values file with the following requirements:

  • File extension: .csv
  • Encoding: UTF-8 (recommended)
  • Headers: First row must contain column names

Required Columns

The CSV must contain exactly these two columns:

  • source: The origin or system name where the log was generated (e.g., "web-server", "database")
  • log_message: The actual log text or message to be classified

Sample CSV Structure

Here's an example of a valid CSV file:

source,log_message
web-server,INFO: User login successful
database,ERROR: Connection timeout
api-gateway,WARN: Rate limit exceeded

Classification Output

After upload, the system will:

  • Add a new column target_label with the predicted category
  • Return the updated CSV file for download
  • Categories may include: INFO, ERROR, WARN, DEBUG, etc.
